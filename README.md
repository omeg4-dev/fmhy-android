# FMHY for Android

Native, offline-first Android client for [FMHY](https://fmhy.net) — fast search, a real
"Recently added" timeline, local bookmarks and automatic base64 link decoding. Unofficial.

- `pipeline/` — Python: builds the dataset from [fmhy/edit](https://github.com/fmhy/edit)
- `schema/` — dataset contract shared by pipeline and app
- `app/` — Android app (Kotlin, Jetpack Compose)
