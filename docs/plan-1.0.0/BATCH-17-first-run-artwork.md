## Entries

### ONB-01: FMHY artwork in the first-run setup

**Problem:** The first-run setup is plain. The images that make the FMHY website recognizable are not used in it, so it does not feel like FMHY. The banner link that was shared (the picture at the top of the FMHY README on GitHub) is a temporary GitHub link that stops working a few minutes after it is created, so it cannot be used directly. The picture has to be saved once and bundled in the app.

**Desired behavior:**

- The setup uses FMHY's own artwork: the banner picture on the welcome step, and the FMHY icon on the other steps where it fits.
- The appearance step shows both list styles in a preview (see UI-01), in the same visual style.
- All images are bundled in the app. The setup never loads images from the web, so it looks right offline and without delay, and no web address is contacted before the user has chosen anything. This fits the no-tracking promise.
- Images look sharp on all screens and in light, dark and pure black. The banner may need a variant for light backgrounds.
- The app keeps saying that it is an unofficial fan project.

**Where FMHY's images come from**

| Image                                           | Where it lives                                                                                                        | Notes                                                                         |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Banner (top of the README)                      | The README page of FMHY's edit project on GitHub (github.com/fmhy/edit). It is the picture the shared link points to. | The link is temporary. Save the file once from the README page.               |
| Logo hero picture                               | Already inside this app's own project, in the folder for images without size variants (fmhy_logo_hero.png).           | May be enough for a first version.                                            |
| Site icon (small logo in the website header)    | fmhy.net/fmhy.ico                                                                                                     | Small. Good for step markers and the FMHY button in the browser bar (BRW-01). |

| Share preview picture                           | fmhy.net/__og_image__/og.webp (1200 by 630)                                                                           | Generated by the website. Could serve as a header image.                      |
| Discord and GitHub icons                        | In FMHY's edit project, folder .github/assets (vector files)                                                          | The same icons the lists use for those links.                                 |
| Wallpapers                                      | fmhy.net/other/wallpapers                                                                                             | FMHY's wallpaper page. Allowed to use. Could serve as backgrounds.            |

**Things to check when implementing:**

- Permission: using FMHY's banner, icon and wallpapers is allowed (decided 2026-10-23). Keep a note of where this permission was given.
- File sizes, so the app stays small.
- Contrast of the banner in light mode.
- That people who already finished the setup do not see it again.
